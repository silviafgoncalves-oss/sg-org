# SG-Org

Agenda digital premium construída com React, TypeScript, Vite, Tailwind CSS, React Router, React Hook Form, Zod, Framer Motion, date-fns, Lucide Icons e Supabase.

## Execução

```bash
npm install
npm run dev
```

## Supabase

Configure `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` no ambiente. Dados de utilizador devem permanecer na cloud; local storage não é usado como armazenamento principal da aplicação.
